# Gym Management System

A simple web-based Gym Membership System developed as a university project.

## Group Members

- Ayanfeoluwa Charis Olayinka — G12S9D
- Uwoh Maximilian Chinanu — GSO976

## Features

- User registration
- User login and logout
- Admin dashboard
- Add gym members
- View gym members
- Delete gym members
- Membership subscription management
- Monthly, Quarterly and Yearly subscriptions

## CRUD Operations

- Create — Add/Register members
- Read — View members
- Update — Manage member information and subscriptions
- Delete — Remove members

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Git
- GitHub

## Database

The project uses a MySQL database called:

`gym_management`

The database structure is included in:

`database.sql`

## How to Run

1. Start a PHP and MySQL server.
2. Import `database.sql` into MySQL.
3. Place the project folder inside your local web server directory.
4. Open the project in a web browser.
5. Register or log in to use the system.
